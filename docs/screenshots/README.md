# Screenshots

Replace the placeholder files in this folder with your own captures.

Expected files:

| File | What to capture |
|---|---|
| `overview.png` | The whole window. Sidebar plus an active conversation. |
| `sessions.png` | Sidebar with several sessions in different states. |
| `permission.png` | A permission request dialog. |
| `projects.png` | The project grouping section, expanded. |
| `options.png` | A session row with its options menu open. |

Capture with `Cmd Shift 4` then `Space` to grab a single window with its shadow.
Aim for a window around 1400 by 900 before capturing, so the images stay readable in the README.
