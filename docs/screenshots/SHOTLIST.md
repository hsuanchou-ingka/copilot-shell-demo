# Shot list

Capture these, drop the PNGs in this folder, and the README image blocks can go back in.

Before you start, resize the window to roughly 1400 by 900 so the images stay readable
once GitHub scales them down. Use `Cmd Shift 4`, then `Space`, then click the window to
grab it with its shadow.

| File | What to capture |
|---|---|
| `overview.png` | The whole window. Sidebar plus an active conversation, mid answer. |
| `sessions.png` | Sidebar with several sessions at once: one generating, one idle, one blocked. |
| `permission.png` | A permission request dialog, showing the command it wants to run. |
| `queue.png` | Two or three messages sitting in the queue above the composer while a turn runs. |
| `resources.png` | The resource rail expanded, showing folder, repository and Notion entries. |
| `artifact.png` | An HTML or Mermaid preview open in the side panel. |
| `background.png` | The background task list with a progress ring part way through. |
